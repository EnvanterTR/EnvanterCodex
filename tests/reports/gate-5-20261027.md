1. Hazır gerçek işyeri hesabıyla kayıt → doğrulanmış e-posta → yıllık plan → ödeme → webhook → tek şirket/owner → gerçek beş adım tamamlama; gerçek sırlar genel rapora yazılmaz.
2. Aynı ödeme dönüşünün tekrarında ikinci şirket/abonelik oluşmaması; başarısız ödeme ve süresi dolan pending siparişte şirket oluşmaması. Mevcut izole testler gerçek sağlayıcı kanıtına eklenir.
3. Normal Demo3 owner girişinden şirket bağlamı ve diğer tenantların bilinen kayıtlarına erişim reddi; destek oturumu bunun yerine kullanılmaz.
4. UI, API ve DB kanıtları aynı senaryonun raporunda ilişkilendirilir; kullanıcı imzası/kimlik doğrulaması taklit edilmez.
