## Bilinçli ürün sınırları

- Kaynak deposu ile müşteriye verilecek kurulum paketi ayrı teslim kanallarıdır. `win-x64` self-contained uygulama ve servis/yedek betiklerini içeren Windows paketi Docker SDK ile üretilebiliyor; imzalı ileri-ileri kurulum sihirbazı ve gerçek Windows Server kabulü henüz yok. Linux kaynak tabanlı Compose paketi için izole üretim kurulum/güncelleme/geri yükleme kabulü geçti; imzalı sürüm, gerçek Ubuntu host/systemd kabulü, kamuya açık TLS ve gerçek hedefte dolu medya ile kurtarma hâlâ açık iştir.
- Etiket kartı C128/C39/Code93/Code93 Extended/Codabar/MSI Plessey/EAN5/EAN13/UPC-A/UPC-E ve QR/PDF417/Data Matrix/Aztec Code biçimlerini, 50×30 ile 100×50 mm arasındaki beş hazır ölçüyü, özel ebatları, hizalamayı ve şirket düzeyinde eşitlenen ayarları destekler. Kamera ile kayıt bulma, çoklu barkod okutarak en fazla 100 varlık seçme, atomik toplu zimmet/iade ve A4/Letter üzerinde sayfa etiket yerleşimi vardır. Üretici, yazıcı modeli ve etiket ürün kodu ile şirket çapında kaydedilen yazıcı/etiket stoğu şablon kataloğu vardır; hazır üretici kataloglarının genişletilmesi sonraki iştir.

Şirket JSON çıktısı tek başına ikili dosyaları içermez; ayrı şirket ZIP dışa aktarımı dosya boyutu/SHA-256 manifestiyle JSON kayıtlarını şirket medyasıyla (logo, varlık ekleri, çalışan belgeleri/fotoğrafları ve şirkete üye kullanıcıların profil fotoğrafları) paketler.
